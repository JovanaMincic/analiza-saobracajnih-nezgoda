# Упутство за покретање

Овај пакет садржи изворни код пројекта за предвиђање тежине исхода саобраћајне
незгоде (материјална штета, повређени или погинули), на скупу од 33.413 незгода
из Србије за 2025. годину. Рађена су два независна приступа која се међусобно
пореде: Јована Минчић кластеризација и неуронска мрежа, а Марко Гордић обрада
природног језика, статистичка анализа и фази систем. Истражна анализа рађена је
заједно.

## Шта је у пакету

- `Skripte - Marko Gordić/`: други приступ (NLP, статистичка анализа, фази систем).
- `Skripte - Jovana Minčić/`: први приступ (кластеризација, неуронска мрежа).
- `Zajednička istražna analiza.py`: заједничка истражна анализа.
- `Podaci/`: подаци за 2025. годину (CSV) и графикони.
- `requirements.txt`: списак потребних пакета.

Укључени су само подаци које скрипте заиста користе, дакле за 2025. годину.
Претходне године нису потребне. OSM фајл (`serbia-latest.osm.pbf`) није у пакету
јер је превелик (око 224 MB); потребан је само за опциони корак 2 и може се
преузети са: https://download.geofabrik.de/europe/serbia-latest.osm.pbf

## Окружење

Потребан је Python 3.11 или 3.12. Виртуелно окружење се прави и пакети се
инсталирају на следећи начин:

```bash
python3.12 -m venv .venv
source .venv/bin/activate        # на Windows-у: .venv\Scripts\activate
pip install -r requirements.txt
```

Главни пакети (све је у `requirements.txt`):

- обрада и анализа: `pandas`, `numpy`, `scipy`, `scikit-learn`
- графикони: `matplotlib`, `seaborn`
- фази систем: `scikit-fuzzy` (тражи `networkx`)
- неуронска мрежа: `tensorflow`

## Подаци и структура

Скрипте користе релативне путање (на пример `Podaci/CSV/...`), па их треба
покретати из корена пакета, где се налази и фолдер `Podaci/`. Структура је:

```
<корен>/
  Podaci/                        (подаци за 2025; CSV и графикони)
  Skripte - Marko Gordić/
  Skripte - Jovana Minčić/
  Zajednička istražna analiza.py
  requirements.txt
```

У Spyder-у радни директоријум треба подесити на овај корен. Скрипте су подељене у
`# %%` ћелије, па могу да се пуштају и ћелију по ћелију.

## Редослед покретања

Препоручени редослед је: прво заједничка анализа, а затим оба приступа.

### 1. Заједничка истражна анализа

```bash
python "Zajednička istražna analiza.py"
```

Прави EDA графиконе у `Podaci/Grafici/` (са префиксом `EDA -`).

### 2. Први приступ (Јована Минчић)

Овај део захтева TensorFlow.

```bash
python "Skripte - Jovana Minčić/Klasterizacija i neuronska mreža.py"
```

Ради кластеризацију (K-means, уз Elbow и Silhouette методу) и обучава неуронску
мрежу. Референтна метрика је F1 (macro).

### 3. Други приступ (Марко Гордић)

Скрипте су нумерисане по редоследу обраде. Кораци 1 и 2 само обогаћују податке
(корак 1 преко интернета са Open-Meteo, корак 2 из локалног OSM фајла) и њихови
излази већ постоје међу подацима, па не морају поново да се покрећу. Анализа су
кораци 3 до 5, и важно је да иду тим редом јер сваки користи излаз претходног:

```bash
python "Skripte - Marko Gordić/3. Obrada opisa (NLP).py"
python "Skripte - Marko Gordić/4. Statistička analiza.py"
python "Skripte - Marko Gordić/5. Fazi sistem.py"
```

Ту су и две помоћне скрипте које праве графиконе и оправдавају дизајн фази
система:

```bash
python "Skripte - Marko Gordić/Pomoćna - Istražna analiza.py"
python "Skripte - Marko Gordić/Pomoćna - Analiza putne mreže.py"
```

Референтна метрика фази система је такође F1 (macro).

## Напомене

- Кораци 1 и 2 код Марковог дела не морају да се покрећу јер су обогаћени подаци
  за 2025. већ у `Podaci/`. Покрећу се само за поновно обогаћивање података:
  корак 1 тражи интернет (Open-Meteo), а корак 2 OSM фајл (линк изнад) и пакете
  `geopandas`, `shapely`, `pyogrio` и `pyrosm`.
- `scikit-fuzzy` за рад тражи `networkx` (оба су у `requirements.txt`).
